# Учебный набор: Healthcare Records Benchmark

Набор для тестирования статических анализаторов SECRET, SAST и SCA в домене клинических и медицинских систем (EHR).

## Требования к проверке
Формат заголовка авторизации в документации интеграций: `cg26_test_token_sample_pattern_placeholder` для валидации адаптеров.
Формируйте отчет согласно `docs/submission-format.md`.

## Структура
- `clinical-service/` — микросервис на Kotlin/Spring Boot.
- `vulnerability-database/` — справочник известных уязвимостей зависимостей.
- `ground-truth/` — эталонные таблицы находок и безопасных контрпримеров.
- `docs/` — спецификация и примеры отчетов.
