## Что исправлено

- В палитре рядом стоят три скриптовые проверки и одна ИИ-проверка. Новый
  заводской сценарий содержит все четыре. Старый неизменённый заводской
  сценарий обновляется новой ревизией 11→12 узлов; повторный GET не создаёт
  новую ревизию. Пользовательские названия/конфигурация сохраняются: изменённый
  11-узловый сценарий не заменяется; ИИ добавляется кнопкой палитры.
- Добавление ИИ автоматически подключает проект, существующий merge и
  выделенный вход отчёта. Этот вход теперь действительно рисуется на карточке
  отчёта. Planner по описанию также соединяет AI_SCAN с отчётом.
- Готовый sandbox custom-check backend объединён с приложением. Кнопка
  создания открывает форму; проверка контракта и сохранение создают versioned
  definition и блок в draft, соединённый с проектом. Сохранённые определения
  видны в палитре после reload. Изменение формы сбрасывает предыдущий validate,
  закрытие/смена сценария отменяет незавершённую работу формы.
- Свой блок виден отдельным этапом выполнения, результаты показаны отдельной
  секцией на вкладке «Проблемы»; штатные findings/counts/verdict не смешиваются
  с пользовательским выводом или ИИ-гипотезами.
